# Sāmwaad — Marketing Website

Marketing site for **Sāmwaad**, an iOS accessibility app that turns spoken conversation into live, speaker-identified captions with AI-generated summaries. Built for people with hearing impairments (ANSD — Auditory Neuropathy Spectrum Disorder).

🌐 **Live site:** [samwaad-app.netlify.app](https://samwaad-app.netlify.app)  
📱 **TestFlight beta:** [testflight.apple.com/join/hyKHQQgu](https://testflight.apple.com/join/hyKHQQgu)

---

## Pages

| Route | Description |
|---|---|
| `/` | Homepage — hero, feature teasers, team strip, TestFlight CTA |
| `/team` | Team Sāmwaad — four members with photos and bios |
| `/features` | Tabbed deep-dive into each core feature |
| `/support` | Support & FAQ |
| `/privacy-policy` | Privacy policy |

## Features covered

- **Quick Captioning** — Live, speaker-aware captions in one tap, wrapped into an AI summary
- **Group Conversations** — Real-time caption sync across a shared room via code
- **Quick Actions** — Schedule recurring conversations with automatic reminders
- **View Conversations** — Searchable history of every session's transcript and summary

## Tech stack

- Plain HTML5, vanilla CSS, vanilla JavaScript (no build step)
- Fonts: [Sora](https://fonts.google.com/specimen/Sora) + [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3) via Google Fonts
- Deployed on Netlify
